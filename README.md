# Vela Electronics — Mini Checkout

A small electronics storefront with a client-side shopping cart and checkout flow. The interface is built with HTML, CSS and vanilla JavaScript. Browser tests use Playwright.

## What it includes

- Two fixed products:
  - Wireless Headphones — ₹1,499.00
  - USB-C Hub — ₹799.00
- Add, remove and adjust product quantities.
- Integer-paise calculations for line totals and the order total.
- Indian Rupee formatting (`en-IN`).
- Required customer-name validation and empty-cart protection.
- A single order-confirmation view with an order reference and itemised summary.
- A synchronous submission guard to prevent repeated order submissions.
- A Playwright end-to-end test suite and saved browser screenshots.

This is a front-end demonstration. It does not process payments or use a backend or database. Cart and order state are held in memory and reset when the page is reloaded.

## Requirements

- Node.js **20.19+** or **22.12+**
- npm

The Node.js version requirement follows the Vite version used by this project.

## Install

```bash
npm install
npx playwright install chromium
```

## Run the app

For Vite development mode:

```bash
npm run dev
```

Open http://localhost:3000.

To serve the files with the project's small Node.js static server instead:

```bash
npm start
```

Open http://127.0.0.1:4173.

## Run the tests

```bash
npm test
```

Run the tests with a visible browser:

```bash
npm run test:headed
```

Open the HTML report generated by Playwright:

```bash
npm run test:report
```

Capture the desktop, tablet and mobile screenshots:

```bash
npm run evidence
```

Create a production build:

```bash
npm run build
```

The `lint` script currently runs the TypeScript compiler (`tsc --noEmit`); it is a type/configuration check, not an ESLint rule set.
